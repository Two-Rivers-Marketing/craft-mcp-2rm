## Decisions

- The four operator decisions are in the decision record (native server, `trm_` prefix, user-permission checks, 2.x security-fix-only).
- Calls the agent made inside the spec that the operator has not confirmed: permission checks inside handlers; `dangerous` narrowed to dev tools; production no longer disables the plugin; conventions resources renamed to `trm://conventions/…`; prompts and the other `craft://` resources deleted.

## Struggles

- v2.0.0 and v2.0.1 shipped on 2026-11-11 with no wiki entry, and `STATE.md` was a month old. Orientation came from git, `CHANGELOG.md` and GitHub instead of the wiki.
- v2.0.0 kept the plugin's own server; the 3.0 decision reversed that a day later, and v2.0.1's `GatedDiscoveryLoader` will be deleted with it.
- The first cut of the `Secrets` port leaked in three ways that only the review sub-agent caught: a config file returning a fluent config object, `db.url` read as `custom.db.url`, and numeric credentials. `Config::getConfigFromFile()` returns `array|callable|BaseConfig`.
- Optional plugins (Neo, Freeform, Navigation, SEOmatic, Commerce) are not in this repo's `vendor/`, so their permission names could not be verified for the spec.
- An operator answer in the question dialog arrived cut off mid-sentence and cost a round trip.
- Tooling: zsh expanded `--include=*.md` and failed several greps; one web search dumped about 12 KB of result text into context; loading `craft\config\DbConfig` in a Pest dataset triggers a PHP 8.4 deprecation from `craft\db\Connection` and marks the whole test file deprecated (use an anonymous stub).
